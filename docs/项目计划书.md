# InkLex 文言实词语境记忆项目计划书

版本：实施计划 v0.3

状态：全文内联释义、独立抽背和 FSRS 间隔复习已实现；按后续需求将主存储改为服务端 SQLite，并增加自动备份与旧浏览器资料迁移。本文保留需求与验收依据，运行及使用方法见仓库 README。

## 一、项目要解决什么问题

做一个面向个人学习的文言实词背诵系统：把课内古诗文和零散的“字词＋释义＋例句”整理到同一个字词库里，让学习者在原句中回忆字词含义，并根据实际记忆情况安排复习。

系统围绕三种使用方式组织：

- **课文学习**：呈现整篇古诗文，标记重点字词；点击后直接在该字词右侧用括号显示本处释义。
- **字词查阅**：查一个字有哪些义项，每个义项在哪些句子中出现，形成跨课文的归纳。
- **独立抽背**：在单独板块中回忆词义、核对答案、反馈记忆情况；包含每天应完成的间隔复习和自主选择范围的练习。

学习目标是：看到一个实词出现在具体句子里，能够想起它在这里的意思，并逐步区分一词多义。

## 三、字库怎么组织

核心关系是：**一篇课文包含多处标注；每处标注指向一个词条的某个义项；同一个义项可以关联多个例句。**

### 1. 词条：这个字词本身

例如“顾”。词条页汇总它的全部义项、例句、来源和学习情况。

### 2. 义项：这个字词的一种意思

例如“顾”可以有“看”和“拜访”等不同义项。这些意思分别整理、分别记录掌握情况。

同义项可以保留不同的释义表述。例如教材和笔记措辞略有差别时，保留各自原文，经过核对后再决定是否归为同一个义项。

### 3. 语境：某个义项具体出现在哪里

保存例句、来源、目标字词在句中的位置，以及这一次出现所对应的原始释义。来自完整课文时，还要关联回课文中的具体位置。

以下仅用于说明结构，正式内容以你提供的资料为准：

| 词条 | 义项 | 例句 | 来源 |
| --- | --- | --- | --- |
| 顾 | 看 | 顾野有麦场 | 《狼》 |
| 顾 | 拜访 | 三顾臣于草庐之中 | 《出师表》 |
| 顾 | 拜访 | 将军宜枉驾顾之 | 《隆中对》 |

在字库中，这是一个“顾”词条、两个义项、三个语境。三条材料都可以回到各自来源。

### 4. 需要遵守的整理规则

- 同一个词在不同文章中出现时，复用词条，补充义项或例句。
- 同形字的不同意思分别保留；相近释义是否合并，需要结合语境核对。
- 同一句中的重复字可以分别标注，避免加点位置含糊。
- 没有全文的零散例句也能独立入库；以后补充全文时可以建立关联。
- 保留原始释义，并允许增加便于理解的学习备注。
- 通假、词类活用、古今异义等先作为可选备注，后续再决定是否单独分类。
- 课文标注与字库使用同一份关联数据，编辑后保持一致。

## 四、资料怎么进入系统

### 方式 A：完整古诗文＋加点词＋释义

你提供篇名、原文，以及需要学习的字词和对应释义。我可以将材料整理成系统使用的结构化数据。

系统中的手动录入流程为：

1. 新建课文并粘贴原文。
2. 选中某一处字词，添加加点或高亮标注。
3. 填入该处释义，关联已有词条和义项，或新建义项。
4. 保存标注在全文中的具体位置，并关联所在句子；抽背时可按需增加上下文。
5. 保存后，全文中的该处字词可以点击展开括号释义，字库中同步出现对应关联。

### 方式 B：字词＋释义＋例句

允许单条录入，也允许批量粘贴。例如：

```text
字词：顾
释义：拜访
例句：三顾臣于草庐之中
来源：《出师表》
```

来源可以后补，但进入正式背诵的材料应具有目标字词、释义和完整到足以理解的例句。暂缺例句或释义的材料可以存为草稿。

### 手动整理的分工

你负责提供已有材料；我可以帮助识别重点词、整理格式、查重、归类和建立关联。原始材料可以保持自然的笔记形式，整理时再转换成统一结构。

遇到释义冲突、疑似错字或加点位置不清楚时，保留来源并标记待核对。未经核对的内容暂不进入每日复习。

## 五、课文学习与独立抽背

### 1. 课文学习：全文展示，点击展开括号释义

进入课文后直接显示完整原文，保留标题、段落、诗句分行和标点。重点字词使用高亮、加点或下划线等可辨认标记，支持电脑点击和手机点按。

每次进入学习页时，释义默认收起。点击某一处标注，在该字词右侧插入本处的释义；再次点击该处即可收起。

交互示意如下，实际学习页展示整篇文章：

| 状态 | 正文中的显示 |
| --- | --- |
| 点击前 | 三**顾**臣于草庐之中。 |
| 点击“顾”后 | 三**顾**（拜访）臣于草庐之中。 |
| 再次点击后 | 三**顾**臣于草庐之中。 |

具体排版和交互规则：

- 括号释义紧跟目标字词，作为正文的一部分自然排版和换行，展开时让后文顺延，避免遮挡或重叠。
- 点击多处字词可以同时保留各自释义，提供“收起全部”方便重新回忆。
- 同一个字在全文中出现多次时，各处独立展开，并显示对应语境中的释义。
- 多字词语将括号放在整个词语后；较长释义允许正常换行，在手机窄屏下保持可读。
- 正文先显示你提供的释义；补充笔记和其他义项可从词条详情查看。
- 原始全文与标注分别保存，括号是显示时插入的内容，便于编辑、搜索和导出原文。

全文页主要用于阅读、回忆和查阅。点击次数与展开时长可作为阅读记录，正式记忆评估由独立抽背中的自评提供。

### 2. 从课文学习进入复习计划

课文页提供“加入学习计划”，可选择整篇的重点词或其中一部分。零散例句中的义项也可从字库加入。

加入的内容先进入待学队列。阅读后可点击“开始本篇抽背”进入独立抽背板块，对这些新义项完成首次回忆和自评，再生成下一次复习时间。已在计划中的义项沿用原有进度。

### 3. 抽背板块：独立入口，两个用途

| 模式 | 内容如何选取 | 对复习计划的影响 |
| --- | --- | --- |
| 今日复习（默认入口） | 优先处理已到期义项和重学任务，再按每日新增量学习新义项 | 每次自评更新记忆状态及下次复习时间 |
| 自选抽背 | 可选一篇或多篇课文、已学字库或易忘义项，并设置题量进行随机练习 | 默认单独保存练习记录，原有到期计划继续保留 |

随机选题在所选范围内进行，同一组练习默认对同一义项去重。新词出现在自选抽背中时，可以加入学习计划，正式学习时再建立调度记录。

“开始本篇抽背”会定位到本篇的新学或到期任务。首页仍保留其他篇目的待复习数量，方便完成全部计划。

### 4. 一次抽背的流程

抽背题目显示来源和足够理解词义的原句，突出目标字词，释义先隐藏：

> 《出师表》
>
> 三**顾**臣于草庐之中。
>
> 请回忆“顾”在这句话中的意思。

先在心里回忆或口头作答，再点击“查看释义”。答案可以沿用“顾（拜访）”的展示方式，下方按需展开笔记、上下文和其他例句，然后给出本次自评：

| 选择 | 含义 |
| --- | --- |
| 忘记了 | 没想起来，或理解成了另一个意思 |
| 有点吃力 | 想了较久，最终想起 |
| 记得 | 能正常回忆 |
| 很熟练 | 能迅速、确定地回答 |

正式复习在完成自评后记录结果并更新计划。只翻看答案或中途退出的题目保持待完成，方便回来继续。忘记的内容在核对答案后进入算法安排的重学。

第一版采用自评，适合文言释义存在多种正确表述的情况。自由输入和自动判分可放到后续阶段。

## 六、记忆曲线与每日复习：第一版必需功能

“艾宾浩斯遗忘曲线”体现了记忆会随时间衰退的规律。本项目通过**主动回忆＋按表现调整的间隔重复**安排复习，把它落实为每天实际需要完成的任务。

### 1. 调度方案

第一版计划接入成熟的 FSRS 间隔重复算法实现。每次正式抽背后，将实际复习时间和四档自评交给调度器，保存记忆状态和下次到期时间。

目标保持率初始建议设为 90%，作为可调整的排期参数。它是算法用于安排间隔的估计目标；更高的目标通常意味着更多复习。初期使用算法的默认参数，积累真实记录后再考虑个性化参数优化。

“第 1、3、7、14、30 天”可以作为理解间隔逐渐拉长的示例。实际间隔由复习历史和本次表现决定，科学复习也需要学习者先主动回忆、再如实反馈。

### 2. 每天应该发生什么

1. 首页分别展示已到期待复习、待学新义项和今天稍后需要重学的数量。
2. 点击“开始今日复习”，进入独立抽背板块，先处理已到期内容和重学任务。
3. “忘记了”触发重学并缩短后续间隔；持续记得的内容逐步延长间隔。“有点吃力”用于成功但费力的回忆。
4. 每次评分后保存结果，显示下一次安排；今天稍后到期的任务保留时间提示。
5. 按可调整的每日新增量补充新义项。复习积压较多时提示减少新增量。
6. 漏学后保留所有未完成任务和原到期时间，再次打开时按到期时间与重学状态安排顺序，并依据实际复习时间重新计算后续间隔。

用户可以分多次完成当天任务。页面持续区分已完成、尚未完成和今天稍后到期的任务，进度随每次评分保存；次日按用户本地日期显示任务。

### 3. 复习进度按什么保存

以 **“词条＋义项”** 为主要记忆单位：

- “顾＝看”和“顾＝拜访”分别调度。
- “顾＝拜访”在多篇课文中出现时，共享该义项的记忆进度；各次答题保留实际使用的句子和来源。
- 出题使用已学习的关联例句，逐步轮换语境，减少只凭固定句子位置作答的情况。
- 新增例句先供阅读，再纳入复习选句范围；文章和字库中的同一义项沿用同一份进度。
- 同一义项只维护一个当前到期时间，按计划进行的重学可以在同一天再次出现。

查阅记录、自选练习记录和正式复习记录分别保存。点击原文查看释义记录为查阅；正式抽背自评驱动间隔安排。这样系统能够区分“看过答案”与“成功回忆”。

### 4. 可查看的学习结果

第一版展示每个义项的上次复习、下次复习、最近反馈，以及每日完成情况和易忘义项列表。后续若增加记忆变化图，应明确区分算法估计与实际答题记录。个体的长期记忆效果需要通过持续使用观察。

## 八、第一版范围与后续扩展

第一版应完整打通以下流程：

**录入材料 → 关联词条和义项 → 阅读全文或例句并按需展开释义 → 加入学习计划 → 独立抽背并自评 → 算法生成复习安排 → 到期再抽背。**

优先完成：

1. 课文与零散例句两种录入方式。
2. 一词多义、同义项多例句、来源关联。
3. 全文展示、重点词标记、点击展开右侧括号释义及收起操作。
4. 独立抽背板块，支持今日复习和自选范围练习。
5. FSRS 调度、首次学习、到期复习、遗忘后重学和漏学后的任务保留。
6. 字词搜索、易忘义项筛选和基础学习统计。
7. 学习进度持久保存，以及内容与进度的备份、恢复。

间隔复习属于第一版的交付条件，需要随学习流程一同验证。

后续扩展候选包括图片识别、自动提取标注、自由输入判分、一词多义对比练习、课外陌生语境测试、跨设备同步，以及隐藏整段原文的全文背诵练习。这些功能在基础流程试用后再排优先级。

## 九、实现方向与数据保存

建议先做适配手机和电脑的网页应用，优先照顾电脑整理资料、手机阅读和背诵的操作体验。

核心数据至少包含：课文、词条、义项、例句或标注、学习计划、复习状态，以及区分查阅、自选练习和正式复习的记录。保存实际评分时间、使用的例句、自评分、算法状态、下一次到期时间、调度参数及版本，便于恢复和核对安排。

各类数据使用稳定编号关联，原文保持独立保存。编辑全文后需要校验标注位置；涉及移动或删改的标注进入核对流程，确认后再用于学习。修改释义时保留历史关联；删除或合并内容时处理好已有进度。

采用单用户服务＋SQLite 文件数据库。课文、字词、设置和复习进度自动写入运行服务的电脑或服务器；浏览器读取同一服务的数据。更换或清空浏览器后，重新连接即可继续。首次使用时自动尝试迁移旧版浏览器资料，并保留原始副本。

代码与示例资料保存在 GitHub，运行时数据库单独保存在数据目录。Git 拉取用于更新代码；日常学习由服务自动保存。多人或多设备同时写入时以数据库版本校验防止覆盖。远程访问需要把同一服务部署到长期可用的主机，当前默认提供电脑本机运行方式。

每次成功保存同步更新当日 JSON 备份，保留最近 30 份每日文件。读写失败时明确显示状态，未确认保存的抽背题保持可重试。服务重启后沿用已有数据库与到期安排。

备份需要覆盖原文、原始释义、关联关系、学习计划、调度设置及复习记录，并标记格式版本。恢复后沿用原有到期时间和记忆状态。导入时检查重复项，已有数据的覆盖需要明确选择。

## 十、建议的推进顺序

### 第一步：用少量真实资料验证结构

选一篇有标注的课文，加上约 10—20 条零散材料。其中至少包含一词多义、同义项跨课文出现、同句重复字、多字词语、较长释义和没有全文的例句。

产出：一份整理好的样本，以及全文内联释义、字词页和独立抽背的示意。验证手机和电脑上的括号释义排版、点击展开与收起，以及题目是否符合你的背诵习惯。

### 第二步：完成资料管理和关联

实现课文录入、标注、全文内联释义、词条与义项管理、搜索和例句关联，让两种来源的材料可以互相查找。

### 第三步：完成每日学习流程

实现独立抽背、首次学习、自评、FSRS 调度、到期与重学队列、自选练习和进度保存。将课文页的学习入口与首页的每日任务接入同一份计划，形成可以连续使用的版本。

### 第四步：用真实学习过程验收

用可控时间验证首次学习、不同自评、当天重学、跨日、漏学和中断恢复；核对算法输出的到期时间。再通过真实使用观察易忘义项和复习负担，调整默认学习量和交互。短期功能验证与长期记忆效果分别记录。

## 十一、第一版验收标准

- 一篇课文的重点词标注完成后，字词库里能找到对应词条、义项、例句和来源。
- 课文学习页呈现完整原文并保留段落和诗句分行，重点词可以点击。
- 点击标注后，释义以“字词（释义）”出现在右侧正文中；再次点击可收起，并支持收起全部。
- 多处同时展开、较长释义、多字词语及手机窄屏情况下，正文正常换行，释义与原文不重叠或互相遮挡。
- 同字多次出现时，只展开被点击的那一处并显示本处释义；展示括号不改写存储的原文。
- 零散例句能直接入库，不要求先建立完整课文。
- 同一词的不同义项能分别学习和记录进度，相同义项不会因来自多篇课文而生成重复的正式复习任务。
- 同句中出现多个相同字时，能够明确当前考查的位置。
- 抽背拥有独立入口，今日复习与自选抽背的范围、记录和对复习计划的影响符合约定。
- 抽背先显示语境和目标词，主动揭示后才显示释义；只看答案未评分时，正式任务保持待完成。
- 查阅释义记录为查阅，正式自评记录为复习；首次学习评分后产生后续到期安排。
- 通过可控时间和不同评分历史验证 FSRS 的状态及到期输出，忘记后产生重学安排；刷新或关闭页面后仍能恢复。
- 同一天稍后到期、跨日、漏学、按篇筛选和每日新增量限制下，未完成任务都能被再次找到和继续完成。
- 自选练习保留其独立记录，已有正式计划的到期时间保持一致。
- 修改例句或释义后，课文页、字词页和背诵页使用一致的数据。
- 编辑全文后能识别失效或错位标注，待核对内容确认后再进入正式学习。
- 待核对材料不会混入正式复习。
- 备份恢复后，内容、关联关系和学习进度完整，重复导入不会静默产生重复数据。

## 十二、样本试用后再收敛的选择

目前可以先按本计划推进。拿到样本后，再根据你的实际使用习惯确定：

- 使用场景主要是初中、高中还是其他阶段，释义以哪套教材或笔记为准。
- 重点词的具体标记样式使用高亮、加点还是下划线；右侧括号释义的展示方式已确定。
- 手机与电脑自动同步是否属于第一版必需能力。
- 自选抽背的常用范围、题量，以及每日新增量；每日间隔复习和独立抽背已确定为第一版必需功能。

这些选择用于完善交互和实现范围；当前最先要验证的是“全文点击查看括号释义、统一字词库、独立抽背、每日间隔复习”能否连贯地支持你的学习过程。
