# 词库义项清理说明

本轮清理解决不同资料使用不同语序、标点或引号，导致同一核心义项被拆成多张复习卡的问题。

## 本轮结果

- 字词条目保持 **2590** 个。
- 核心义项由 **6728** 个减少为 **6661** 个，共合并 **67** 个重复义项。
- **8265** 条例句全部保留，没有删除原句、出处或本句释义。
- 61 组语序、标点或引号等价项已合并，其中一组含三个重复义项，因此共减少 62 个。
- 人工确认【背】的“背叛／违背，背叛”，以及【并】的“合／合并”“一齐／一起”“皆／都”属于相同核心义项，再减少 5 个。
- 按同一规则复查后，确定等价的重复项剩余 0 组。

例如，【并】的“兼并，吞并／吞并，兼并”现在共用一个核心义项；【背】的“背叛／违背，背叛”共用“违背，背叛”。各资料原来的具体措辞继续保存在例句的“本句释义”中。

## 合并边界

自动规则只处理以下差异：

- 同组释义的排列顺序不同；
- 中文逗号、顿号、分号不同；
- 直引号与弯引号不同；
- 空格及末尾标点不同。

文字包含关系不会自动合并。例如“合”“合并”“合，合并”仍作为后续审阅候选，因为仅凭字符串包含无法判断所有语境是否属于同一核心义项。通假、词类活用、不同词性、不同读音及真正不同的古义继续分开。

## 数据保护

核心义项与本句释义分开保存。合并时只重新关联义项编号，例句的原始释义、出处和校录说明保持不变；已有卡片和历史记录会迁移到保留义项。如果两个待合并义项都已有独立复习状态，自动清理会跳过该组，避免擅自选择进度。

迁移只执行一次。执行前数据库自动生成 `data/backups/before-sense-cleanup-20261101-v2-*.json`，可用于完整核对或恢复。新增资料、手工录入和备份合并现在使用同一等价规则，避免这些确定重复项再次出现。
