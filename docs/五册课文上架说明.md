正文只去掉明确的 `**字词（解释）**` 随文注释外壳，保留目标字词；教材页码移入篇目说明。保留源文件用字、标点、段落、诗句分行、非注释括号、戏曲舞台提示和篇章出处，仅去除 Markdown 行末排版空格。未自行检索或改写其他教材版本；源文件没有明确列出的作者、朝代暂留空。

《陈情表》采用用户在对话中追加的完整版本，结尾为“臣不胜犬马怖惧之情，谨拜表以闻。”。追加版本保存在 `resources/sources/陈情表_用户补全文.md`，仅还原了粘贴时转义的 Markdown 标记。该补充文本的加粗范围跨越多处解释，且部分注释未加粗，因此单独按配对括号去除解释（包含嵌套括号），正文保持用户提供的四段结构；全量提取表中的 121 条《陈情表》释义已按当前正文重新定位。

其他篇目的来源文字由 PDF 提取，有断行和空格，尚未逐字校勘，因此不能把“已上架”视为教材版本准确性的保证。

两份源文件原样保存在 `resources/sources/`。`scripts/extract_textbook_articles.py` 整理书架正文；`scripts/build-textbook-glosses.mjs` 校验四列表格、还原重复字词的具体位置并生成 `server/content/textbook-glosses.json`。生成包记录来源 SHA-256；9 处只有右引号的释义仅补齐左引号，不改写解释。

服务启动时一次性安装课文与随文释义，两个步骤均在导入前自动备份。字词按原词合并、义项按释义合并；已有学习设置、卡片、评分和阅读记录保持不变。若某个位置已有个人标注，以个人标注为准并跳过该条内置标注。后续编辑、删除或完整恢复备份后，重启不会重新灌入。

本次 3757 条记录均已定位；同句重复字词通过原表顺序和原始加粗位置自动还原，无需再次手工补录。
