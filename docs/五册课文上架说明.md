# 五册课文上架说明

本批只将用户提供的《高中语文五册_文言文古诗词_实词补充整合版.md》中的 71 篇原文放入课文书架。后续“字词＋本处释义＋原句＋篇目”的整理由用户完成，再交回校验与关联。此次没有新增词条、义项、例句、阅读记录或复习计划。

| 册次 | 篇数 |
| --- | ---: |
| 必修上册 | 19 |
| 必修下册 | 17 |
| 选择性必修上册 | 10 |
| 选择性必修中册 | 8 |
| 选择性必修下册 | 17 |

按文件中的册次、篇目顺序收录，包括其中的现代词作、词曲和戏曲节选。课文书架的「课内」分类显示 71 篇，三篇已有示例《小石潭记》《陋室铭》《爱莲说》保留在同一书架的「课外」分类。可搜索篇名、册次或原文。

正文只去掉明确的 `**字词（解释）**` 随文注释外壳，保留目标字词；教材页码移入篇目说明。保留源文件用字、标点、段落、诗句分行、非注释括号、戏曲舞台提示和篇章出处，仅去除 Markdown 行末排版空格。未自行检索或改写其他教材版本；源文件没有明确列出的作者、朝代暂留空。

《陈情表》采用用户在对话中追加的完整版本，结尾为“臣不胜犬马怖惧之情，谨拜表以闻。”。追加版本保存在 `resources/sources/陈情表_用户补全文.md`，仅还原了粘贴时转义的 Markdown 标记。该补充文本的加粗范围跨越多处解释，且部分注释未加粗，因此单独按配对括号去除解释（包含嵌套括号），正文保持用户提供的四段结构。没有把补充释义拆成词库记录。

其他篇目的来源文字由 PDF 提取，有断行和空格，尚未逐字校勘，因此不能把“已上架”视为教材版本准确性的保证。

源文件原样保存在 `resources/sources/高中语文五册_文言文古诗词_实词补充整合版.md`，随文释义并未丢弃。`scripts/extract_textbook_articles.py` 仅整理书架文本，输出 `server/content/textbook-articles.json`，其中包含来源 SHA-256 和格式疑点；没有执行词库提取。

服务启动时一次性安装此批课文，导入前自动备份到 `data/backups/before-textbook-five-volumes-20261031-v1-*.json`。同标题、同正文去重；同标题但不同正文保留为不同版本，不覆盖个人资料。后续编辑、删除或完整恢复备份后，重启不会重新灌入。

后续字词表建议每行提供：`篇目｜原句｜字词｜本处释义`。同句中目标字重复时再注明“字词在句中第几处”；若同一句在篇内重复，也注明句子的具体段落或第几处，便于准确关联到书架原文。
