## 答案核对

答案由本次整理补齐，每空单独保存。按现有《陈情表》完整原文及公开原文核对，生僻字不沿用旧版资料提取中的缺字：《离骚》第5题保留“鞿羁”，第14题保留“蕙纕”“揽茝”。

- 《离骚》原文核对：[古文岛原文](https://www.gushiwen.cn/shiwenv_1997f465971c.aspx)。
- 《兰亭集序》原文核对：[故宫博物院《兰亭序》释文](https://www.dpm.org.cn/lemmas/245215.html)。通假字仍采用题目课文的“悟言”等写法。
- 《陈情表》第26题第一空在原 DOCX 中只有空白，没有下划线，已还原为“以孝治天下”的填空位；第38题跨段的第三空已并回同一题。
- 《陈情表》第33题首空可写“日薄西山”或连同上文写“但以刘日薄西山”；少数首句是否包含“且”“此地有”“又有”等前接词的合理形式作为备选答案保存。

逐字核对只忽略标点、空白与全／半角排版差异，不自动把同音字、形近字或缺字判为正确。错字、多字、漏字分别显示；未输入时允许口头背诵并自评。核对结果不代替使用者对回忆难度的四档自评。

## 背诵与复习

主导航和今日学习页都可进入“理解性默写”。题库支持按篇目、题意和“已加入计划／曾经忘记”筛选，可以单题背诵或将筛选结果加入计划。

“自由抽背”可按题号或随机出题，选择题量，单独记录练习，不改正式到期时间。“今日复习”按同一 FSRS-6 引擎安排，先到期题后新题。默写的新题上限独立设置，默认每日10道，沿用凌晨3点的学习日边界；目标保持率沿用学习设置。

只查看答案、离开或刷新都不评分。完成四档自评且服务确认写入后才进入下一题；保存失败时原题和输入保留，可重试。刷新后已评分题的状态和记录继续保留；未评分题仍在待完成队列中。忘记后由 FSRS 安排分钟级重学，到期题不受新题上限限制。

## 持久化与复现

题库、默写卡片、输入内容与评分记录存于现有 SQLite 的 `recitation` 字段，包含在自动备份、完整导出、合并和恢复中。旧版没有该字段的备份继续兼容；合并时现有默写计划和个人答案优先。

启动通过 `understanding-recitation-20261105-v1` 一次性补入，导入前保存完整快照，不覆盖原有课文、字词、设置或进度，不预先生成复习卡片。重复启动不重复导入，完整恢复旧备份后也不强制重新添加已移除的资料。

原始文件只保存在本地 Git 忽略目录 `resources/local-sources/`。运行 `python scripts/build_recitation_content.py` 可重现提取；题库及来源指纹在 `server/content/recitation.json`，逐空答案表在 `scripts/recitation-answers.json`。运行应用与测试不需要原始文件。
