## 原文与译文

从 DOCX 的正文 XML 按原段落顺序提取。只选择阅读篇目的原文及其相邻全文译文，不将现代文、默写零句、选项、题号、得分点或鉴赏分析混入正文。金山材料中的括号字词解释转换为可点击标注，段号及脚注号移出正文；端州、埒、子方、惠崇／郭熙、子猷访戴等注释在课文简介中保留，完整原注仍可查原始文件。

全文译文没有补写或改写。仅移除译文段落编号与排版空格，再按原文句号、问号和叹号对齐；原文一句对应原译多句时，合并显示其完整译文。依绿堂第⑤、⑥段共用的原译段落已拆开，分别对应问句与答句。抽取脚本逐篇断言所有全文译文字符按原顺序出现且只出现一次；保存后所有 98 条都可在现有译文编辑器中继续编辑。

原资料另在第17题重复给出的《李孔昭传》单句翻译，已有对应的全文译文覆盖，没有重复插入正文。出处、具体原段号、提取前原文、原译及源文件 SHA-256 均在 `server/content/exam-articles.json` 中留档。

仅作以下标点整理，字词不变：

- 《李孔昭传》第③段依所附第18题断句答案及全文译文，为“阅数日……吏闻趋谢罪”补标点。
- 《依绿堂记》末段问句“履屐之下与”补问号。
- 《林仁肇传》末段为陈乔引语补引号，整理后续句读。

“国家衅其利”“至时”“雨蓑雪蓬”“娥皇、舜英”“几研”等原资料字句、异体字均按来稿保留；没有静默替换为推测文字。原译中可能的笔误也未擅改。

## 字词释义以原文标注为准

88 处字词释义全部直接采用资料的明确标注，包括原文中的括号释义，以及第14题中“事＝侍奉”的明确答案。整句译文可以意译，字词义项仍逐处精确保留原标注，不用译文反推、替换或扩充义项，也不因两者措辞不同而列为待核对。

例如“币”的原标注是“钱币”，全文译文写“书信和礼物”，字词释义仍显示“钱币”；“得”的原标注是“完成，实现”，整句译文写“找到了他”，字词释义仍保留“完成，实现”。这两层内容分别保存，所有 88 处标注均可点击并可加入学习计划，不自动生成学习卡片或评分记录。

只有缺少释义、目标字位置不明确或原文无法准确对位等资料不完整的情况，才保留为待核对或待补；整句意译与逐字释义的表达差别不是待核对依据。

## 保存与升级

原始 DOCX 保存在本地的 `resources/local-sources/`，该目录已被 Git 忽略，不随源码上传。结构化资料保留来源文件名、SHA-256、阅读篇目原文与译文的原段号，供核对。要重新提取，将三份原始 DOCX 放入该本地目录，再运行 `python scripts/extract_exam_articles.py`，即可按已复核的句段对应表重新生成内容文件。`scripts/exam-articles-review.json` 记录原文每句所对应的原译句数；运行应用与测试无需原始 DOCX。

服务启动时通过 `exam-articles-2026-11-v1` 一次性补入。导入前在 `data/backups/` 保存完整 JSON 快照，备份失败则整个导入回滚。已经有相同正文或将该选段包含在全文中的篇目时，沿用已有条目，仅补充缺失、没有冲突的译文和字词标注。已有个人原文、译文、备注、标注、设置与学习进度优先，不覆盖。

重复启动不会再次添加；后续个人编辑或完整恢复备份的结果也不会被旧资料重新覆盖。导入不创建学习卡片、不增加复习或查阅记录。当前数据库已实际执行此导入，而不仅是把内容放在源码中。
