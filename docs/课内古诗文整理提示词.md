# 课内古诗文整理提示词

复制下面整段给外部模型，再附上你整理好的教材原文和注释。生成的 JSON 发回后再校验、转换入库；它是资料交换格式，不是「完整备份」格式。

```text
请把我随后提供的课内古诗文整理为用于语境背诵的 JSON，只处理我提供的资料，不自行增加篇目。先等我发资料，再开始整理。

要求：
1. 严格保留原文用字、标点、段落和诗句分行；不要混用其他教材版本，不擅自改错字或补缺文。疑点写入 notes。作者、朝代、教材版本或出处不知道就填空字符串，不猜测。
2. 优先按我提供的加点词与教材释义标注；若只有原文，提取高中学习重点实词、虚词、通假、古今异义和词类活用。释义必须对应本句语境，不罗列无关词典义项；活用和通假说明放在 note 中。
3. 直接在原文相应位置把目标词包成 [[a1|字词]]，每处使用独立编号。相同字出现多次也必须分别定位、分别编号和解释，不能只标第一次，不能全局替换。同一位置不重复或嵌套标注。编号在每篇内唯一，与 annotations 中的 id 一一对应；word 必须与标记中的原文字词完全一致。
4. annotatedText 是完整原文加定位标记。去掉标记、保留其中字词后，必须逐字还原我给的原文。不要计算字符偏移，不另输出整篇译文。
5. 释义或位置有疑问时设置 needsReview: true，并在 note 说明；无法定位时不要硬插标记，写入该篇 notes。needsReview: false 仅表示本轮整理未发现疑问，不代表经过权威校勘。
6. 输出合法 JSON，不加 Markdown 代码围栏或额外说明。字符串内的换行用 \n，双引号正确转义。篇目较多时分批，每批只输出完整篇目，不在文章中间截断。

固定结构如下（内容仅示范格式，不要作为课文输出）：
{
  "format": "inklex-articles-v1",
  "articles": [
    {
      "title": "篇名",
      "author": "",
      "era": "",
      "source": "教材版本、册次或原资料出处；未知则留空",
      "annotatedText": "[[a1|顾]]而[[a2|顾]]。",
      "annotations": [
        {"id": "a1", "word": "顾", "meaning": "这一处的释义", "note": "", "needsReview": false},
        {"id": "a2", "word": "顾", "meaning": "另一处的释义", "note": "", "needsReview": false}
      ],
      "notes": []
    }
  ]
}

输出前检查：原文完整；每个标记编号都有且仅有一条注释；每条注释都有对应原文位置；重复字按具体语境分别处理；没有擅自增删原文。
```
