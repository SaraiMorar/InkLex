# InkLex · 温故知新

个人文言实词学习应用。在完整原文中点击重点字词，展开右侧括号释义；将义项加入计划后，通过独立抽背完成间隔复习。

## 拉取与启动

安装 Node.js 24 或更高版本，然后执行：

```bash
git clone https://github.com/SaraiMorar/InkLex.git
cd InkLex
npm ci
npm run build
npm start
```

应用默认监听本机 5173 端口。首次启动会自动创建 SQLite 数据库，无需额外安装数据库服务。以后启动只需在项目目录运行 `npm start`。

开发时运行 `npm run dev`，网页和数据接口由同一个开发服务提供。预览生产网页可用 `npm run preview`。

更新代码：停止服务，执行 `git pull --ff-only`、`npm ci`、`npm run build`，再运行 `npm start`。运行时数据目录已排除 Git 跟踪，代码更新会继续使用原来的数据库。

应用使用 React、TypeScript、Vite 和 Node.js 内置 SQLite。它是供个人使用的一套共享学习空间。

## 开始学习

1. 在「课文书架」打开一篇文章，点击标记的字词，释义会显示为 `顾（拜访）`。再次点击或使用「收起全部」隐藏释义。
2. 选择重点义项，点击「加入学习计划」或「开始本篇抽背」。同一义项跨文章共享进度，不同义项分别记录。
3. 在「抽背与复习」完成「今日复习」。先回忆、查看答案，再选择忘记／吃力／记得／熟练。
4. 首页展示到期、待学、今天稍后到期的任务。正式评分后才更新记忆状态；查阅和自选练习单独记录。
5. 在「资料与设置」添加全文、标注和零散例句，调整每日新增量与目标保持率。

「课文书架」内分「课内」「课外」两类：「课外」收录《小石潭记》《陋室铭》《爱莲说》三篇可编辑示例，原有标注与学习进度继续保留。「课内」收录五册教材篇目。添加或编辑文章时可通过「课文分类」调整分类；仅切换分类不会让标注失效。示例释义请以个人教材口径核对。

页面右上角的「外观模式」可选择跟随系统、浅色模式或暗色模式。默认跟随系统，手动选择会保存在当前浏览器；不同设备可使用各自的外观偏好，学习资料仍保存在服务端。

另已收录用户提供的《高三一模二模春考高考300实词整理》：**300 个字词、1665 个义项、2295 条例句**，保留词性、出处和原表位置。其中 73 条疑似错字、出处或释义问题标为「待核对」，暂不参加抽背。详见[录入说明与校录记录](docs/高三300实词录入说明.md)。

更新后启动服务，这批资料会一次性补入现有数据库；同字同义合并，已有课文、笔记、学习设置和复习进度保留。导入前自动保存 `data/backups/before-gaosan-300-v1-*.json`。重复启动不会重复导入，用户后续编辑或完整恢复备份的结果优先。

在「字词库」搜索具体字词、例句或「高三300实词」即可查看；选择义项「加入计划」后参加记忆曲线复习，也可直接到「自选抽背」练习。导入不会把全部义项自动加入计划。

另已补充本次提供的高频实词、150 实词及 18 个文言虚词资料，去重后新增 **1575 条例句**（其中 271 条待核对），默认库共 **390 个字词、3903 条例句**。在字词库搜索「高频实词」「150实词」「18虚词」可查看。新版启动时一次性补入，自动备份并保留原进度；9 条缺少目标字的原句单独留档。详见[补充词库录入说明](docs/补充词库录入说明.md)。

## 资料录入

新增「理解性默写」：仅从本次提供的材料收录《陈情表》42题、《离骚》20题、《兰亭集序》15题，共 **77题**，逐空答案已补齐。支持按篇目和题意筛选、口头背诵或输入默写、查看答案及错漏字核对、四档自评、随机／顺序抽背和独立的 FSRS 默写复习计划。默写进度随服务自动保存，并包含在完整备份中。详见[理解性默写录入说明](docs/理解性默写录入说明.md)。

已按用户提供的五册整合文件在课文书架上架 **71 篇原文**，同一书架的「课外」分类另有 3 篇，可按篇名、册次或原文搜索。用户整理的全量提取表已关联 **3757 处随文释义**，覆盖全部 71 篇；课文中的点击标注、字词库和抽背共用同一批义项与例句。《陈情表》采用用户追加的完整版本。见[五册课文上架说明](docs/五册课文上架说明.md)。

另从《2026高三一模传记文言实词梳理-总》加入 **16 篇课外材料、605 处字词释义和 447 句对应译文**。译文按原文句号显示在各句下方，可以隐藏、编辑或只补录一部分；课内篇目也预留同一套逐句译文录入位置。原始 PDF 保存在 `resources/sources`，重复启动不会重复导入。

另从金山二模及 10 月 30 日周测答案上架 **6 篇课外古诗文、98 条完整对应译文和 88 处字词标注**：《书端州郡斋壁》《李孔昭传（节选）》《依绿堂记》《林仁肇传（节选）》《一掌园记》《秋声赋》。字词释义直接采用原文标注，整句译文保留原资料的意译，不因两者措辞不同而修改释义或排除抽背。静安答案订正缺少完整原文，保留资料待补。启动时先备份、去重，再一次性补入，不覆盖已有学习内容与进度。详见[练习卷课外古诗文录入说明](docs/练习卷课外古诗文录入说明.md)。

词库已按核心义项与本句释义分层清理：语序、标点和引号不同但含义相同的义项共用一张复习卡，本句仍显示各资料的原始解释。首轮合并 67 个确定重复义项，例句和出处均未删除；包含关系不会自动合并。详见[词库义项清理说明](docs/词库义项清理说明.md)。

- 全文：在「课文书架」添加或打开课文，点击「编辑标注」，直接点原文中具体的那个字，填写这一处的释义；点击已有标注可修改。词组勾选「选择词组」，依次点击起字和止字。原文编辑也在书架内完成。
- 零散例句：填写字词、释义、例句和可选出处。已有义项可以关联，保留本处原始释义。
- 批量例句：粘贴 Tab 分列的数据，每行依次为 `字词、释义、例句、出处（选填）、第几次出现（默认 1）`。可直接从表格复制。整批校验通过后保存。
- 编辑全文会将原标注转为待核对，并清空无法继续准确对位的逐句译文；保存后可按新原文重新录入。

需要用其他模型整理课内古诗文时，可复制[课内古诗文整理提示词](docs/课内古诗文整理提示词.md)。采用原文内的唯一编号定位重复字；生成后交回校验、转换入库，不要作为完整备份直接恢复。

## 复习算法

使用锁定版本 `ts-fsrs@6.0.0` 的现代 `DefaultScheduler` API，显式选择 **FSRS-6**，默认目标保持率 90%，使用内置默认权重。学习步骤为 1 分钟、10 分钟，重学步骤为 10 分钟，关闭时间扰动，保留完整原生复习日志和前后状态。

每日新增量默认为 10 个义项，学习日按浏览器本地时间凌晨 3:00 划分；00:00—02:59 的学习计入前一天。首页的今日已复习和最近七天记录也按同一规则统计。到期任务不受新增量限制。漏学保留原到期时间，评分时按实际时间计算后续安排。调整保持率后，已有到期任务保留，新评分使用新设置。

记忆曲线由该义项的真实 FSRS 状态计算，标明算法估计。它是排期依据，长期记忆效果需结合实际使用观察。

## 数据自动保存在哪里

默认保存在项目目录中的 `data/inklex.sqlite`。课文、字库、设置、复习计划和完整历史都保存在这里。浏览器负责显示与操作，更换或清空浏览器不影响已保存的数据。

- 每次操作通过数据接口写入 SQLite，收到成功响应后才推进抽背进度。
- 数据库使用 WAL、FULL 同步写入与事务版本检查，多个窗口或设备同时操作时重新读取最新版本后重试，避免覆盖其他窗口的评分。
- 服务重启后自动打开已有数据库；遇到损坏或不支持的数据时报告错误，保留原文件。
- 启动时自动尝试迁移旧版 `localStorage` 资料，成功后保留原始副本并标记已迁移。新建服务完整接纳旧资料；已有服务合并新增内容并保留服务端已有进度。冲突或损坏会显示迁移提示，原始数据可以下载核对。

可通过环境变量 `INKLEX_DATA_DIR` 指定固定数据目录，例如在 macOS/Linux 中：

```bash
INKLEX_DATA_DIR=/path/to/inklex-data npm start
```

这样项目代码可以独立更换位置。`PORT` 可调整端口，`HOST` 可调整监听地址，默认分别为 `5173` 和 `127.0.0.1`。

## 自动备份与设备共享

每次成功保存后，服务会原子更新 `data/backups/inklex-YYYY-MM-DD.json`（按 UTC 日期分组），保留最近 30 份每日备份。文件格式可直接在「资料与设置」中导入。自动备份失败会明确提示，已经成功写入数据库的数据仍然保留。

也可手动「导出完整备份」。导入支持合并新增资料，或经明确选择后完整恢复；原有的内容与进度均可迁移。JSON 文件同时适合额外存档。

同一服务下，多个浏览器共享同一份进度。如果想让手机和电脑随时共用，需要将这套服务部署到长期可用的主机，并让两端访问同一个地址。在两台电脑上分别克隆并启动，会各自产生独立数据库。当前默认是本机个人运行；面向公网部署时应在反向代理上配置访问控制和 HTTPS。

GitHub 保存项目源码、依赖锁文件和示例资料；实时数据库及自动备份位于 Git 忽略目录中。日常复习不需要 Git 提交。纯静态 GitHub Pages 无法运行本项目的数据服务。

## 验证

```bash
npm test
npm run build
npm run test:e2e
```

核心测试覆盖真实 FSRS 排期、遗忘重学、跨日与每日新增限制、义项归并、重复字定位、原文编辑失效标注、备份完整性和重复导入。数据库测试覆盖实际 SQLite 文件、服务重开后的记录恢复、并发版本检查、自动备份及备份失败。浏览器测试覆盖桌面与手机尺寸下的阅读、正式抽背、自选练习、录入、备份恢复、旧资料迁移与写入失败重试。

浏览器测试默认使用 `/usr/bin/chromium`。其他系统可以通过 `CHROMIUM_PATH` 指定已安装的 Chromium 路径。测试会在 5183 端口启动独立服务，并使用临时数据目录，避免修改个人资料。截图和失败追踪写入已忽略的 `test-results/`。

完整需求与后续方向见 [项目计划书](docs/项目计划书.md)。

抽背与复习的范围选择支持按篇名、作者、册次搜索，并可用「全部／课内／课外」标签筛选。默认按筛选结果出题，也可点选篇目缩小范围；修改搜索或标签会重新按筛选结果选定范围。未筛选时的「全部资料」包含独立例句，无匹配结果时不能开始抽背。

我的字词库支持默认顺序、拼音正序／倒序、义项最多、例句最多、复习时间最早、忘记次数最多七种排序，可切换卡片或列表展示。显示偏好保存在当前浏览器，不改变词库或学习进度。复习时间取每个字词已有复习记录且例句已核对的义项中最早的到期时间，未开始复习的字词排在后面；忘记次数统计正式复习和自选抽背中的「忘记了」记录。
